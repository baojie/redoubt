## Why these changes

**Why did we do this?**

To build a deterministic tactical shooter aimed at the Squad-like genre from
zero, laying down the core rules engine, the headless simulator and the
network layers in one pass — while putting the documentation, the test gates
and the "no commercial assets" constraint in place first.

**What problem did it solve?**

A pure-function, per-tick bit-identical authoritative core, so that server
adjudication, client prediction and batch-match testing all replay the same
match; terrain, ballistics, cover and the first-person view stepping from
procedural placeholders toward something playable.

**What will it affect in the final deliverable?**

Established the verifiable M0–M3 baseline: 100 headless matches with zero
crashes, reproducible hash across seeds — the ground M4 vehicles, the soldier
model and the real rifle build on.
