## Why these changes

**Why did we do this?**

The rifle the player holds deserves to be a real model rather than primitives,
and the first-person arms had started reading as tubes instead of limbs — so
the viewmodel work was about making the gun and the body around it believable
in the same frame.

**What problem did it solve?**

Two judgement calls that only a human eye can make: the elbow of a derived
procedural arm projected off-screen, which is why the visible arm was a
straight pipe — so elbows and shoulders are now explicit joints chosen by
projecting back from where they should appear on screen. And on the reliability
side, an event with no listener used to be silently dropped; the core now makes
that impossible.

**What will it affect in the final deliverable?**

The first-person view is now visually honest (real rifle, human arms), the
event system can be trusted under load, and the docs — README, CHANGELOG,
daily logs, commit messages — are all in English going forward, including the
LAN multi-player how-to that the README was missing.
